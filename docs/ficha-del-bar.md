### Problema con la web (24-09-2026)

- El dominio `bardelabuelo.es` sigue apuntando a un servidor (el DNS funciona),
  pero ni quien lleva el proyecto ni Claude pueden abrir la página.
- La web tiene una versión en `/it/` (italiano), típica de los creadores de webs
  de algunos hostings italianos como Aruba. **Sin confirmar.**
- Causas probables: el plan de hosting ha caducado o está suspendido, o el
  certificado de seguridad (https) ha caducado.
- Siguiente paso: saber qué mensaje de error sale al abrirla y quién paga o
  gestiona la web.
