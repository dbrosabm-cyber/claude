# Bar del Abuelo · Parla

Proyecto digital del **Bar del Abuelo** (Calle Zamora 2, Parla): diseño, redes
sociales, automatizaciones, web y llamadas con IA para tomar pedidos.

Todos los datos del bar están en [`docs/ficha-del-bar.md`](docs/ficha-del-bar.md).

## Estructura

```
.
├── CLAUDE.md                  Instrucciones y contexto para Claude
├── docs/
│   └── ficha-del-bar.md       Datos del bar, canales, marca y decisiones
└── herramientas/
    └── revision-chatgpt/      Script aparte: revisar con ChatGPT lo que hace Claude
```

Las carpetas de cada área (diseño, redes, llamadas, web…) se crean cuando
empiece el trabajo en ellas.

## Hoja de ruta

Sin orden fijo: se avanza poco a poco.

- [ ] **Imagen**: logo en buena calidad, colores y plantillas en Canva (carta,
      plato del día, partidos, eventos, reseñas)
- [ ] **Redes**: conectar Instagram, Facebook, TikTok y Google Maps a
      Metricool; calendario de publicaciones; nada se publica sin visto bueno
- [ ] **Poner orden**: mismo nombre, horario (8:00–24:00, todos los días) y
      teléfono en Google, Just Eat, Uber Eats, Glovo, redes y directorios
- [ ] **Web**: averiguar por qué no carga `bardelabuelo.es`; arreglarla o hacer
      una nueva con la carta, el horario y los enlaces de pedido
- [ ] **Llamadas con IA**: un agente que contesta y toma el pedido
      (presupuesto de 10–20 €/mes)
- [ ] **Automatizaciones**: avisos de reseñas nuevas con borrador de respuesta,
      eventos que se publican solos, resumen semanal de las redes
